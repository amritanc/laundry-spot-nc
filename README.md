# The Laundry Spot website

A simple responsive HTML/CSS/JavaScript website for The Laundry Spot in Durham, NC.

## Included
- `index.html` — website content
- `styles.css` — responsive styling
- `script.js` — mobile navigation and footer year
- `assets/laundry-spot-logo.png` — logo supplied by the business

## Business details currently included
- Address: 1019 Holloway Street, Durham, NC 27701
- Phone: (919) 251-8955
- Hours: 9:00 AM–8:00 PM every day
- Self-service pricing: varies by machine; customers are directed to check the price displayed on each machine.

## Preview
Open `index.html` in a web browser.

## Publish
Upload the contents of this folder to a GitHub repository and connect that repository to Netlify. Then add `www.LaundrySpotNC.com` in Netlify's domain settings and follow the exact DNS instructions Netlify provides for Porkbun. Do not guess or manually substitute DNS records.

This is a starter website and has not yet been published or connected to the domain.
